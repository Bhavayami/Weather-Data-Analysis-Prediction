# Weather-Data-Analysis-Prediction(PYTHON and NumPy)
This project analyzes monthly temperatures of 5 cities with prediction and visualizations using Pandas, NumPy, and Matplotlib
Description
This project analyzes **monthly temperature data of multiple cities** using **Python, NumPy, and Pandas**.
Basic statistical analysis is performed, and a **simple linear trend method** is used to predict temperatures for the month of **June**.
The results are visualized using multiple plots for comparison and trend analysis.

**Tools & Libraries Used**
- Python
- Pandas
- NumPy
- Matplotlib
- Excel (.xlsx dataset)

**Analysis & Tasks Performed**
- Loaded monthly temperature data from Excel
- Calculated **average, minimum, maximum, and standard deviation** for each city
- Predicted **June temperature** using a linear trend approach
- Identified:
  - City with highest average temperature
  - City with highest temperature increase (Jan–May)
- Visualized:
  - Monthly temperature comparison
  - Predicted June temperatures
  - Temperature trends using line plots
  - Average temperature and increase comparison using bar charts
